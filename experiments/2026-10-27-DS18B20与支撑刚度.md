**日期**：2026-10-27
**主题**：8.1 震动状态监测器 · 第二路传感接入 + 安装/支撑刚度对测量的影响

## 1. DS18B20 温度通道

### 1.1 器件信息

| 项目 | 值 |
|---|---|
| 型号 | DS18B20（防水探头 + 带接线端子模块） |
| ROM 地址 | `28:9C:52:23:7D:25:0B:DD`（家族码 0x28，确认为 DS18B20） |
| 分辨率 | 12 位（0.0625 ℃/LSB） |
| 接线 | 探头：黄→DAT、红→VCC、黑→GND；模块：DAT→GPIO5、VCC→3V3、GND→GND |
| 上拉 | 模块板载 4.7 kΩ（丝印 `472`），无需外接 |
| 库 | OneWire 2.3.8 + DallasTemperature 4.0.6 |

### 1.2 三项验证

**① 稳定性（静置 90 秒）**

```
均值 24.370 ℃   范围 24.250 ~ 24.500 ℃   标准差 0.085 ℃
前 5 个读数：24.50 × 5（完全不变）
后 5 个读数：24.25 × 5（完全不变）
```

读数呈"成段恒定 + 缓慢下台阶"，台阶高度正好 0.0625 ℃（1 个 LSB）。
**结论：传感器噪声低于自身分辨率**，90 秒内的 0.25 ℃ 变化来自环境温度漂移，不是测量噪声。

**② 响应性（手指捏住探头 30 秒）**

```
30.19 → 31.00 → 31.56 → 32.06 → 32.44 → 32.75 → 33.00 → 33.19 → 33.38 ℃
总升温 3.25 ℃
```

分段升温量：+0.81、+0.56、+0.50、+0.38、+0.31、+0.25、+0.19 ℃
**速率单调递减，为典型一阶热响应**，时间常数 τ ≈ 25 ~ 30 s。

**③ 恢复性（松手后 100 秒）**

```
32.62 → 32.06 → 31.50 → 31.00 → 30.50 → 30.06 → 29.75 → ... → 28.12 ℃
总降温 4.50 ℃
```

平滑指数衰减，无迟滞。**响应可逆。**

### 1.3 结论与设计含义

- 温度通道可用，精度取决于 DS18B20 出厂标定（数据手册 ±0.5 ℃）
- **τ ≈ 25~30 s 意味着温度报警必须设分钟级确认延时**，否则手碰探头即误报
- 表面温度与 MPU6050 芯片温度相差 1~4 ℃，二者物理含义不同，不可混用

## 2. 支撑刚度对振动测量的影响（重要发现）

### 2.1 现象

同一台风扇、同一转速（35.2 Hz），振动 RMS 在一天内出现 **0.055 g 与 0.207 g** 两种水平，相差 **3.7 倍**。

### 2.2 排查过程

**第一次误判**：怀疑传感器粘接松动。

按压传感器模块（手指轻按 MPU6050，保持 15 秒）：

```
按压前：0.1846 g
按压时：0.0796 g     （下降 56.9%）
```

据此判断为"传感器胶松了"。

**重新粘贴传感器后复测**：

```
重新贴紧后：0.2068 g     ← 没有改善，反而略高
```

**说明第一次判断错误。** 按压传感器时，手指同时给整个风扇结构加了阻尼，
两个因素混在一起无法区分。

**第二次判断（正确）**：改为按压**风扇底座**（远离传感器）：

```
按压前：0.2068 g
按压时：0.0556 g     （下降 73.1%）
```

0.0556 g 与历史稳定值 0.055 g 几乎完全一致。

**结论：风扇整体在桌面上跳动（刚体运动），而非传感器粘接问题。**

### 2.3 判别指标：基频峰值 / 带内 RMS

两种状态下的谱特征差异明显：

| 状态 | 基频峰值 | 带内 RMS | **峰值/RMS** |
|---|---|---|---|
| 固定良好 | 0.042 ~ 0.062 g | **0.0556 g** | **≈ 1.0** |
| 风扇在晃 | 0.066 ~ 0.079 g | **0.1966 g** | **0.36** |

风扇晃动时，额外能量**不在 1× 转频上**，而是分布在其他频率（低频整体运动），
因此 1× 峰值几乎不变而带内 RMS 大幅上升。

**该比值可作为"支撑是否可靠"的在线判据**：
比值显著小于 1 时，说明测量中混入了大量非 1× 成分，数据不可信。

### 2.4 修复与结果

把风扇四角固定于桌面后：

```
带内 RMS: 0.197 → 0.0722 g（降 2.7 倍）
峰值/RMS: 0.36 → 0.82
转频:     35.2 Hz 稳定
```

### 2.5 结论

> **支撑刚度对振动测量的影响（3.7 倍）远大于传感器粘接质量。**
>
> 传感器无法区分"设备自身结构振动"与"设备整体刚体运动"。
> 工业标准要求振动测量必须相对于刚性基础进行，且机组基础须有足够刚度，
> 原因即在此。本方案在实验台架上必须保证风扇刚性固定。
